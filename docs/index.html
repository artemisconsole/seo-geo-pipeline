The standard we aim for

What "good" looks like at each stage — the bar, not the how.

Plan

All 7 tabs complete and client-approved within ~4 weeks; Quick Win + strategy locked before execution.

Tracking

GA4 · GSC · GBP · booking events all firing, measured & logged; historical data recovered from the client.

Content

Lint-pass (no em-dash / cliché), EEAT-sourced, GEO answer chunks + entities + the standout attribute, internal links + CTA.

Technical

Sitemap · robots · llms.txt · schema · hreflang clean; good Core Web Vitals; no index blockers on money pages.

Brand & GEO

The standout attribute (root / rare / unique) is consistent on-site and across the web, and drives the prompt set.

KPI

Must-hit: organic + AI traffic ↑ · committed keyword ranking ↑; higher tiers add AI visibility & citation.

Reporting

Weekly internal (Asana) · monthly client (Agency Analytics) · executive 6/12-month (Canva) — on time.

Gate

PIC → SEN → AM/PM → client. Claude never sends to the client; L approves cost; Dev / Client make heavy site changes.
